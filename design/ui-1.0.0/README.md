# 1.0 工作台与设置设计

本次采用内置 Image Gen 生成的完整工作台与设置页概念，并在现有 React / Tauri 应用中实现。参考图仅用于设计，界面与控件全部为代码，未将设计截图铺在应用中。

- [工作台设计](workbench-concept.png)：空白导入状态、三栏编辑器、显式示例入口、静态风格色带、导出设置。
- [设置页设计](settings-concept.png)：独立分类导航、主题缩略图、强调色、画布与动态效果、导出默认值、指南。

## 设计约定

沿用项目的平面创作工作台，用细分隔线组织内容。主题使用语义变量；深色以 `#16181c` / `#1d2025` 为底，浅色以 `#f6f7f9` / 白色为底。强调色只用于主动作、选中态与参数反馈；浅色主题使用较深的强调色以维持可读性。图片像素和导出结果不参与主题变化。

字体使用本机 Segoe UI / Microsoft YaHei UI，参数控件 13 px，侧栏标题 15 px，设置标题 28 px。布局维持左侧参数、中央画布、右侧风格和导出；设置页有独立滚动区。所有主题和偏好变化即时生效，不保存图片内容。

## 生成提示与范围

使用内置 Image Gen，未使用 CLI。两次提示分别要求：

1. 完整的中文 Shinkou Pixel 三栏 Tauri 编辑器，近黑灰底、浅绿强调、清晰细边框、空白导入画布，顶部工作台 / 设置导航，禁用的无图片动作，手动「打开示例」、静态色带预设、本地状态栏；禁止自动示例图片、营销页面、装饰指标和嵌套卡片。
2. 同一设计体系的完整设置页，外观 / 默认导出 / 使用指南 / 关于导航，浅色 / 深色 / 跟随系统缩略图、绿蓝紫强调色、减少动态效果、棋盘格 / 纯色、导出格式 / 倍率、三步指南和可选 AI 环境说明。

## 实现核对

Browser 插件及 browser 技能未提供，使用已安装 Playwright 驱动本机 Microsoft Edge。截图和临时验证脚本保存在项目外的会话可视化目录，不提交运行报告或浏览器配置到项目。

## 行为验证

验证流程：空白启动 → 设置主题、强调色与导出默认值 → 刷新后恢复 → 系统深浅色变化 → 导入真实灯塔图片 → 160×120 转换 → 参数修改与撤销 → 原图对比 → 切换设置后像素校验保持一致 → 2x WebP 下载 → 移除图片 → 手动示例 → 使用指南。

检查页面标题、有效内容、无框架错误覆盖层、主题属性、真实下载文件头、无横向溢出、无应用脚本异常。AI 服务未运行时的连接失败单独归类为预期状态，界面显示启动说明；本轮不执行大型模型生成。截图脚本读取画布校验值引发的 Canvas2D readback 性能提示来自验证操作。

构建与测试：`npm run build`、`npm test`（14 个测试文件，84 项通过），以及 Tauri Release / NSIS 构建。最终交付仅保留发布程序和安装包，删除重新生成的 Rust / Vite 编译缓存。

最终版本按用户要求设为 **1.0.0**。概念图中的 0.11.0 为设计阶段占位版本号。已通过 `view_image` 检查两张设计稿与最终浏览器截图，并在 1487×1058 / 1586×992 原始概念尺寸及 1440×900 / 390×844 视口对照布局、字号、间距、主题色、控件和首屏文案。保留上述明确的功能扩展，无未处理的裁切、重叠或横向溢出。

最终 Windows 1.0.0 EXE 通过独立 WebView2 配置目录验证：空白启动、原生窗口深色 / 浅色切换及 API 返回值、打包示例的真实 160×160 转换和移除图片，无脚本错误或主题同步警告。NSIS 安装向导未运行。

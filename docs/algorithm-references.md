# 算法参考与实现取舍

本文记录 perfectPixel 与 SLIC 的适用范围，以及本项目 0.6.0 采用的方法。参考项目的用途与 Shinkou Pixel 不完全相同，以下区分原项目方法、当前实现与尚未接入的能力。

## perfectPixel

检查版本：[`72096de5`](https://github.com/theamusing/perfectPixel/tree/72096de5cf1bff9102687c4f89af6f62c4273a86)。参考 [项目说明](https://github.com/theamusing/perfectPixel/blob/72096de5cf1bff9102687c4f89af6f62c4273a86/readme.md) 与 [实现](https://github.com/theamusing/perfectPixel/blob/72096de5cf1bff9102687c4f89af6f62c4273a86/src/perfect_pixel/perfect_pixel.py)。

它面向已经具有像素风格、但像素块尺寸或对齐不准确的图片。主要流程是频域估计网格、通过梯度修正网格位置，再在格子内采色；提供中心、逐通道中位数和局部主簇等采样选项。

| 方法 | 对本项目的启发 | 当前处理 |
| --- | --- | --- |
| 周期性与网格检测 | 对 AI 生成的伪像素画或被放大的像素素材，可先恢复其潜在网格 | 尚未接入自动 FFT 网格检测；普通动漫插画未必有可靠的格子周期 |
| 梯度驱动的网格位置修正 | 应先考虑边缘位置，再将区域放入格子 | 当前保持用户指定的规则输出网格，通过区域得分和轮廓规整选择颜色，不移动网格线 |
| 格内中心、中位数或主色采样 | 不必把格内所有颜色直接平均 | 当前区域映射已选择已有色板色；新增 SLIC 净化也按区域投票选主色，不生成 RGB 中间值 |

因此，perfectPixel 的网格恢复适合未来作为独立的输入模式。直接将该网格检测用于任意插画，会把发丝、描边或背景纹理的重复间距误当作像素尺寸。本次没有引入其 Python/OpenCV 运行环境，也没有复制其源代码。

## SLIC

参考 [EPFL 原作者说明](https://www.epfl.ch/labs/ivrl/research/slic-superpixels/)、[论文记录](https://doi.org/10.1109/TPAMI.2012.120) 与 [VLFeat 的实现说明](https://www.vlfeat.org/api/slic.html)。SLIC 在颜色与二维位置组成的空间中进行局部聚类，得到贴合局部颜色边界的超像素。它不提供语义识别，也不直接输出方形像素画。

当前加入独立 TypeScript 实现 [slic.ts](../src/engine/slic.ts)，作为结构保真模式中的可选区域净化。它在过渡归并之后、最终网格映射之前运行，默认强度为 0。

### 分区

颜色空间使用 D65 白点的 CIELAB；原有色板量化仍使用 Oklab。聚类距离为：

$$
D_{pk}^2=\|\mathrm{Lab}_{CIE}(C_p)-\mu_k\|_2^2+\left(\frac{m}{S}\right)^2\|(x_p,y_p)-(x_k,y_k)\|_2^2.
$$

$m=10$。设分析图与输出图的宽高分别为 $(W_a,H_a)$、$(w,h)$，种子间距取：

$$
S=\mathrm{clip}_{[6,24]}\left(\mathrm{round}\left[2\min(W_a/w,H_a/h)\right]\right).
$$

每个包含不透明像素的种子格提供一个初始中心。在格子中心的 3 × 3 有效邻域内选择低梯度点；中心为空时，使用格内离中心最近的不透明点。这里梯度代价为有效四邻域的 CIELAB 差平方和，接触透明像素时增加固定代价。这样可以覆盖透明背景上很小的孤立主体。

执行六轮局部分配与均值更新：每个中心只搜索横纵各 $\pm S$ 的窗口；窗口移动后未被访问的点保留上一轮分配。最后按四连通分裂标签。与常见的碎区域并入邻居步骤不同，当前保留小连通分量，避免仅按面积抹除细线与高光。

### 区域净化

分区本身不修改图像。对每个四连通区域，使用已有的量化色板标签投票，权重为 $0.1+0.9S_p$；重要度 $I_p\ge0.2$ 的细节不参与主色投票。这里 $S_p$ 是原有的邻域颜色一致性，与种子间距 $S$ 不同。

记净化强度 $u\in[0,1]$。只有主色权重占比至少为 $0.95-0.25u$ 时，才尝试将其他像素归入该主色。每个被修改的像素还须满足：

- 细节重要度 $I_p<0.2$；
- 邻域颜色一致性 $S_p\ge0.5$；
- 当前色板色与区域主色的 CIELAB 距离不超过 $2+10u$。

输出仍为原色板中的颜色，透明度保持不变。分区均值仅用于聚类，不写回 RGB 图像。薄阴影与微小色差仍可能被简化，因此该选项默认关闭，也不作为“更高质量”的统一预设。

### 验证与计算位置

单元测试覆盖弱碎色归并、受保护细节、黑色单格线、透明度、孤立不透明点、四连通标签、确定性及总色数约束。README 的 SLIC 对照图由正式流水线生成，完整参数见 [examples.json](examples.json)，可使用 `npm run docs:examples` 重建。

该阶段目前在 CPU Worker 内运行。GPU 模式仍加速采样、色彩调整、细线分析与最近色匹配。SLIC 额外分配分析缓冲区并执行六轮聚类，分析图越大，额外耗时与内存占用越明显。

# Shinkou Pixel 使用指南

## 从空白工作台开始

启动应用后不会自动打开或处理测试图片。点击 **导入图片**、按 `Ctrl + O`，或将文件拖入工作台。支持 PNG、JPEG、WebP、BMP、GIF、AVIF，单张最大 60 MB；GIF 仅读取首帧。

内置图片保留在 **打开示例** 入口，需要手动选择。图片信息栏可替换或移除图片。关闭应用不会覆盖原图；重新打开应用时回到空白工作台，不会恢复上一张图片。

## 选择转换参数

1. 动漫、卡通、插画先选 **结构保真**，照片和风景可尝试 **照片采样**。
2. 从长边 **160 px、32 色** 开始。像素尺寸控制长边格数，并保持宽高比；尺寸越小，颗粒越明显。颜色数量控制自适应色板上限。
3. 选择自然像素或固定风格色板，再调节亮度、对比度和饱和度。固定色板有自己的色数，不能在颜色数量中另设上限。
4. 用 **对比** 拖动分界线查看原图与结果。缩放只影响预览，导出倍率另行设置。网格取色可读取结果中真实像素的颜色与行列位置。
5. 32–64 px 可尝试低像素重构，并分别调整结构清晰度、描边和五官；极小的五官、侧脸和复杂纹理仍可能被简化。使用撤销 / 重做比较参数变化。

**计算设备**只控制普通图像处理流水线。自动 / GPU 模式在硬件不可用时回退 CPU；底栏显示实际使用设备。它不会更改 ComfyUI 重绘服务的设备配置。

## 导出清晰的像素

- **1x** 保存真实像素尺寸，适合后续编辑。例如 160 × 120 的结果仍为 160 × 120。
- **2x / 4x / 8x** 使用最近邻整数倍放大。例如 4x 导出为 640 × 480，每格边缘保持清晰。
- 需要透明背景时，开启 **保留透明度** 并选 PNG。WebP 使用浏览器的最高质量编码，不承诺无损；PNG 为无损格式。
- 点击当前色板的导出图标可保存 GPL 文件，供 Aseprite / GIMP 使用；点击色块可复制 HEX。

## 设置与主题

顶栏 **设置** 或 `Ctrl + ,` 打开设置页，`Esc` 返回工作台。切换页面不会清除当前图片、转换参数、预览或撤销历史。

| 选项 | 行为 |
| --- | --- |
| 浅色 / 深色 / 跟随系统 | 即时切换全应用外观；跟随系统会响应 Windows 主题变化 |
| 萤草绿 / 晴空蓝 / 鸢尾紫 | 统一改变主按钮、选中态和参数控件的强调色 |
| 棋盘格 / 纯色画布 | 只改变工作区背景，不修改图片或导出透明度 |
| 减少动态效果 | 关闭界面过渡；系统的减少动画偏好也会生效 |
| 默认格式 / 倍率 | 自动保存，立即同步到导出面板；工作台临时更改不会改写默认值 |
| 恢复默认偏好 | 恢复跟随系统、萤草绿、棋盘格、PNG 和 4x，保留当前图片与转换参数 |

偏好仅保存在当前设备 / 应用的本地存储中，不保存图片内容。如果本地存储不可写，设置页会提示偏好仅在当前会话生效。

## 区分三种 AI 功能

| 功能 | 作用 | 额外安装 |
| --- | --- | --- |
| AI 线条辅助 | 为普通转换提供原图线稿线索 | 无需 Python / CUDA，模型随应用提供 |
| 五官保真 | 在适用的低像素重构中辅助定位正面动漫五官 | 模型随应用提供 |
| AI 辅助重绘 | 参考原图生成候选，再约束到目标像素网格 | 需要独立的 ComfyUI、Python / CUDA 环境和约 12.5 GB 模型 |

普通像素转换不依赖 ComfyUI。重绘首次运行 `scripts/setup-generation.cmd` 安装，后续运行 `scripts/start-generation.cmd` 启动并保持窗口开启，再在应用中导入图片并选择 **AI 辅助重绘**。已安装环境无需再次下载模型。

生成服务仅连接本机 `127.0.0.1:8188`。模型可能改变角色特征，候选需自行比较后应用。关闭主应用不会自动停止服务；参考图和结果可能保存在 ComfyUI 的 `input` / `output` 目录。

完整环境通常需要 20 GB 以上磁盘空间。可将环境安装到其他磁盘，安装与启动脚本使用相同目录，例如在项目根目录运行：

```powershell
powershell -File scripts/setup-generation.ps1 -RuntimePath "D:\ShinkouRuntime"
powershell -File scripts/start-generation.ps1 -RuntimePath "D:\ShinkouRuntime"
```

已有环境应先关闭服务并完整迁移目录，再用新的 `-RuntimePath` 启动。详细硬件、模型及算法说明见 [本地生成式重绘](generative-redraw.md)。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 导入 / 导出 | `Ctrl + O` / `Ctrl + S` |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Shift + Z` 或 `Ctrl + Y` |
| 打开设置 / 返回工作台 | `Ctrl + ,` / `Esc` |
| 预览缩放 | `Ctrl + 滚轮` |
| 取色移动 / 复制 / 退出 | 方向键 / `Enter` / `Esc` |

输入框获得焦点时，编辑快捷键优先用于该输入框；AI 重绘面板打开时，其快捷键和焦点独立处理。

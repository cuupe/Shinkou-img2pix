# 低像素重构与神经五官辅助

0.9.0 为 32–64 px 提供独立的混合处理路径：用受规则网格约束的颜色区域优化处理形状，再用离散主色投票、连续结构线和原图五官测量提高小网格辨识度。使用预训练 HRNet 定位五官，没有训练新的像素画生成网络，也没有使用扩散生图。

## 启用范围与参数

满足以下条件时启用：结构保真模式、“小尺寸处理”为色块重构、目标长边不超过 64 px，且原图长边大于目标的 1.25 倍。已有小尺寸像素图不进行该重构。96 px 及以上及照片采样模式沿用既有处理。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 结构清晰度 | 70 | 主色簇归并、连续结构线及五官离散重建的强度；0 保留 0.8 的输出；高值可能简化低对比阴影 |
| 描边保留 | 55 | 0 最强弱化细窄的有色深线，100 关闭该弱化；不保证删除所有深色线条 |
| 细节补偿 | 75 | 补偿稳定背景内的短小暗笔画；与原有模式的线条保护共用参数，处理方式不同 |
| 五官保真 | 75 | 神经定位对五官保护、高光及闭口细嘴线补偿的强度；0 不运行五官模型 |
| 过渡色保留 | 25 | 在此路径中控制色板提取时稳定区域与过渡样本的权重，不运行原有逐像素过渡归并 |
| 颜色数量 | 32 | 最终色数上限；固定色板继续严格使用其既有颜色 |

重构路径不再施加旧模式的轮廓规整、碎点合并、SLIC 区域净化和 TEED 细线权重，相关控件在该路径下隐藏。网格取色、导出、撤销和重做均使用同一份最终结果。

## 受约束的区域重构

分析图的宽高最多为目标的六倍，不主动放大输入。色彩调整、原有稳定区域色板提取后，在 CIELAB 空间计算颜色距离。以下位置均以分析图像素为单位。

每个输出像素对应一个输入区域。令 $g_s$ 为规则网格中心，$c_s$ 为该区域当前使用的最终色板颜色，源像素为 $(x_p,\ell_p)$，网格间距为 $S_x,S_y$。局部区域分配最小化：

$$
D(p,s)=\|\ell_p-c_s\|_2^2+28^2\left[\frac{(x_p^{(x)}-\mu_s^{(x)})^2}{S_x^2}+\frac{(x_p^{(y)}-\mu_s^{(y)})^2}{S_y^2}\right].
$$

在每次迭代中，计算区域均色、位置均值，按最终色板更新颜色代表。为避免区域排列变成与输出网格不相容的结构，限制并平滑位移：

$$
\delta_s=\operatorname{clip}(\bar x_s-g_s,-0.45S,0.45S),\qquad
\mu_s=g_s+0.6\delta_s+\frac{0.4}{|N_4(s)|}\sum_{t\in N_4(s)}\delta_t.
$$

实现执行 16 次迭代；分配窗口限制在中心附近一个网格间距内，保留四邻域的网格关系。源图和区域均色分别使用 CIELAB 双边滤波，降低连续阴影碎色，同时避免跨越强颜色边界进行普通均值模糊。最终每格选择一个现有色板颜色，不添加抖动。

该思路参考 [Pixelated Image Abstraction，Gerstner 等，2012](https://cragl.cs.gmu.edu/pixelate/)。本项目独立实现了固定色板约束、有限位移和邻域平滑，**没有复现论文的 MCDA 调色板优化，也不宣称具有其完整收敛性质**。

### 选择性描边弱化

在分析图亮度上计算 $5\times5$ 形态学闭运算 $C(L)$，检测窄暗脊。令 $r$ 为描边保留比例，$u$ 为五官保真比例，$H_p$ 为有足够关键点置信度支持的眼睛/嘴巴区域指示，$a_p,b_p$ 为 CIELAB 色度分量：

$$
R_p=\operatorname{clip}_{[0,1]}\left(\frac{C(L)_p-L_p-3}{18}\right)
\operatorname{clip}_{[0,1]}\left(\frac{\sqrt{a_p^2+b_p^2}-8}{15}\right),
$$

$$
L'_p=L_p+(1-r)(1-0.55q)(1-uH_p)R_p\,[C(L)_p-L_p],\qquad q=\text{pixelClarity}/100.
$$

该式只调整区域分配所用的亮度证据，最终仍从色板选色。它偏向弱化细窄的有色描边；大块暗部、纯黑核心和有依据的眼部细节不被统一刷成浅色。透明度按原有规则网格内的覆盖率决定，不随移动的区域扩张。

### 离散主色与结构线

结构清晰度大于 0 时，区域均值只作为初始参考，最终颜色改由真实分析样本投票。相近色板颜色按 complete-link 距离聚合，组内任意两色的 CIELAB 距离小于 $3+7q$，以源图使用最多的已有颜色作代表；不增加色板颜色，不允许相似色链无限合并成一个大组。

令 $g(k)$ 为颜色组代表，$a(p)$ 为前述源样本区域归属，$k(p)$ 为分析样本最近的色板颜色，区域的投票量为：

$$
V_{s,k}=\sum_{a(p)=s}\left[0.6+0.4e^{-\| (x_p-g_s)/S \|^2}\right][g(k(p))=k].
$$

在有源图投票支持的颜色中选择：

$$
k_s^*=\arg\max_k\left\{\frac{V_{s,k}}{\sum_jV_{s,j}}-0.6(1-q)\min\left(1,\frac{\|c_k-c_s^{\mathrm{initial}}\|^2}{900}\right)\right\}.
$$

五官保护区跳过该主色覆盖，随后单独重建。四连通大小不超过两格的低对比小色簇，只有在较大邻区有源图投票支持、且不接触透明边缘时才合并。

结构线从源图窄暗脊中测量，使用局部二阶矩估计方向，排除低方向性响应。两侧颜色不同的边界需要至少三格的候选连通结构；同色块内部线需要至少八格，并在已检测人物中限制在头部结构范围，减少衣料短折线挤占网格。最终仍选用已有色板中的测得线色及其受控弱化颜色，强度受描边保留控制。这里是颜色、方向和关键点约束，不是新增的头发/服装分割神经网络。实现见 [pixel-clusters.ts](../src/engine/pixel-clusters.ts)。

### 通用短笔画补偿

对原图分析亮度中的紧凑暗脊进行连通分析。只有大小受限、外围颜色足够一致的短笔画参与补偿，长轮廓网络和混色区域被排除。根据实际暗像素估计中心线，按局部网格相位重采样，再选择已有色板颜色。笔画与背景混合比例为 $0.3+0.2d+0.2q$，其中 $d$ 为细节补偿比例。它不依赖人脸模型，可保留部分卡通嘴线或小符号；弱对比度、复杂背景或极小笔画仍可能丢失。

## 真实神经模型

| 项目 | 实现 |
| --- | --- |
| 模型 | hysts 的 HRNetV2-W18，28 个动漫五官关键点 |
| 来源 | [GitHub](https://github.com/hysts/anime-face-detector)、[预训练权重及模型卡](https://huggingface.co/hysts/anime-face-detector-hrnetv2) |
| ONNX | [anime-landmarks.onnx](../public/models/anime-landmarks.onnx)，38,757,312 字节 |
| 版本、输入输出、校验值 | [项目模型卡](../public/models/anime-landmarks-model.json) |
| 网络与权重许可 | [MIT](../public/models/ANIME-LANDMARKS-LICENSE.txt)；导出定义中的 MMPose 部分为 [Apache-2.0](../public/models/MMPose-LICENSE.txt) |
| 人脸候选框 | nagadomi 的 [MB-LBP 动漫人脸模型](https://github.com/nagadomi/lbpcascade_animeface)，[MIT 许可](../public/models/ANIME-LBP-LICENSE.txt)；本项目独立实现分类器执行与框分组 |
| 训练状态 | 使用公开预训练权重，没有在本项目中重新训练或微调 |

模型面向近正面的动漫人脸，不是通用动物五官识别器。候选框最多取四个，在扩大 1.25 倍的方形区域上运行网络：RGB、256 × 256、ImageNet 均值与标准差归一化，输出 28 × 64 × 64 热图。解码使用峰值和四分之一格梯度修正，未使用上游的翻转测试与 DARK 解码。

只有置信度和五官几何关系通过检查的结果才用于后处理：

- **眼睛高光：** 在未经网格采样的原图眼部区域寻找真实的、封闭的浅色小区域，排除与区域边界相连的眼白；眼睛在输出中有足够宽度时，最多为每只眼睛保留一个高光像素。
- **色板预算：** 自适应色板至少有八色时，为有源图支持的高光、虹膜主色及亮部预留最多 $\min(4,\lfloor N/4\rfloor)$ 个色板位置。用源像素最近色频率 $n_k$ 和色板颜色距离估计删除代价，替换代价最小的冗余颜色，保持总色数不变：$k^*=\arg\min_{k\notin R} n_k\min_{j\ne k}\|c_k-c_j\|_2^2$。$R$ 为已预留的位置，避免后续替换覆盖先前的关键颜色。观测颜色应用同样的亮度、对比度和饱和度调整。固定色板不被改写；结构清晰度 0 时仍只使用原有高光预算。
- **闭口细嘴线：** 关键点仅提出搜索区域；还需源图中存在足够窄暗笔画、覆盖列数和稳定背景证据。按测得的中心线重采样，连接容易断开的笔画。张嘴区域或证据不足时不套用细嘴线补偿，不盖上固定的微笑模板。

这属于学习式定位辅助的图像重构，不能等同于学会了手绘像素画风格。五官位置、姿态和表情仍可能识别错误；侧脸、遮挡、很小的人脸和卡通动物常会使用通用重构。

### 原生小网格的五官布局

0.9 在源图眼睛多边形内测量真实虹膜的主色、亮部、位置和眼睑暗色。用眼下实测背景排除多边形中混入的皮肤，避免将单色眼睛误判成有肤色虹膜；无足够明暗/色度证据时不生成该观测。虹膜颜色统计的长边采样上限为 192，避免超大原图带来不受控的排序开销；原有高光小岛检测仍读取原图像素。

每只适用眼睛在目标格上评估水平和垂直 $\{-0.25,0,0.25\}$ 格的九种源采样相位，按自身测得的眼睑、虹膜和浅色区域分类投票，评价源图覆盖与关键类别的保留。高光与虹膜落在同格时，在源图确有虹膜支持的邻格中联合分配，避免两者互相覆盖。最终一格一色，使用当前色板；没有固定眼睛贴图，也没有统一复制某种瞳色。

闭口嘴线另在未缩小的原图中测量窄暗笔画、实际线色与中心线。过密暗区、张口几何或证据不足时跳过；按测得曲线的底部相位落格，使一格左右的原图弧度在 48/64 px 下仍有机会表达。极小的 32 px 嘴形仍可能只剩短线，不能保证完整保留原始表情。实现见 [semantic-features.ts](../src/engine/semantic-features.ts) 和 [semantic-reconstruction.ts](../src/engine/semantic-reconstruction.ts)。

## GPU、缓存与回退

所有处理在本机 Worker 内进行。五官模型随程序提供，运行时不下载模型、不上传图片，也不需要 Python、CUDA 或服务密钥。

五官网络通过 ONNX Runtime Web 1.31.1 使用 WebGPU / WASM。GPU 强制使用模型原生 NCHW 布局：在测试的 Intel gen-12lp 设备上，默认 NHWC 重写产生了错误热图，改为 NCHW 后 CPU/GPU 关键点及峰值最大误差约为 $3.6\times10^{-7}$，并确认了 921 次 GPU 队列提交。这是所测设备的结果，不代表所有驱动均已验证。

模型会话及当前源图的识别结果缓存复用。更换尺寸、描边、色板或五官强度不会重复识别同一张图；切换 CPU/GPU 或更换输入时重新分析。未发现候选人脸时不加载约 37 MiB 的五官模型。GPU 初始化/推理失败时尝试 WASM；模型无法运行时保留完整的几何重构并显示原因。高分辨率路径中的 TEED 使用方式不变。

## 验证与复现

```powershell
npm test
npm run test:reconstruction
npm run docs:examples
```

硬件验证脚本实际加载模型，比较 CPU/GPU 输出、检查真实 GPU 提交、验证源图虹膜、高光与嘴线测量，以及 32/48/64 px 最终网格的 CPU/GPU 一致性，并检查 160 px 行为不变。需要支持 WebGPU 的真实硬件和浏览器。`scripts/compare-upgrade.mjs --before` 可在改动前保存图像基线，改动后运行同一脚本验证结构清晰度 0 与基线逐像素一致，并导出实际升级对比；私有素材不写入 README。

ONNX 重建使用 [export-anime-landmarks.py](../scripts/export-anime-landmarks.py)，上游提交与权重校验值固定。该脚本仅供开发者重建模型，不是应用使用前提：

```powershell
python scripts/export-anime-landmarks.py --upstream PATH_TO_PINNED_UPSTREAM --weights PATH_TO_PRETRAINED_SAFETENSORS
```

README 的对比图片由真实应用算法生成，完整参数、模型执行方式与输入 SHA-256 见 [examples.json](examples.json)。这些例图不构成跨素材质量保证；实用结果仍取决于构图、原始线宽、目标尺寸和色数。
